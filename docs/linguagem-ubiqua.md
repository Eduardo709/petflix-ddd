# Linguagem Ubiqua - Petflix

| Termo | Significado no negocio | Contexto |
| --- | --- | --- |
| Tutor | Usuario comum que assiste e publica videos do proprio pet | Identidade / Comunidade |
| Especialista | Usuario com selo (veterinario, adestrador, groomer) que responde nos foruns | Identidade / Forum |
| Administrador | Usuario com permissao de moderacao | Moderacao |
| Video | Conteudo educativo ou de entretenimento sobre pets; raiz de agregado | Catalogo |
| Thumbnail | Imagem de capa obrigatoria do video | Catalogo |
| Categoria | Classificacao tematica (alimentacao, saude, adestramento, curiosidades...) | Catalogo |
| Envio | Ato de submeter video + thumbnail; gera `VideoEnviado` | Catalogo |
| Publicacao | Video processado e visivel no feed; gera `VideoPublicado` | Catalogo |
| Feed Geral | Lista paginada dos videos publicados mais recentes | Catalogo |
| Feed Seguindo | Lista dos videos de quem o usuario segue | Comunidade |
| Seguir | Relacao entre dois perfis | Comunidade |
| Visualizacao | Registro de que um video foi assistido | Engajamento |
| Favorito | Video salvo pelo usuario para rever depois | Engajamento |
| Assistidos | Historico de visualizacoes do usuario | Engajamento |
| Forum / Topico / Resposta | Espaco de perguntas e respostas com especialistas | Forum |
| Denuncia | Sinalizacao de conteudo improprio | Moderacao |
